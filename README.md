# 🌲 OOTY TRIP 2026 🚗

A mobile-optimized web application built for group trips, expense tracking with Splitwise logic, spot guides, live polls, itinerary planning, and trip recap features.

## 📱 Features

- **💳 Expense Tracker**: Real-time expense logging with dynamic categories (Food, Fuel, Hotel, Tea, Snacks, Entry Tickets).
- **⚖️ Subpage Splitwise**: Per-person expense breakdown & minimal debt settlement algorithm.
- **📸 Ooty & Coonoor Guide**: 40+ photo spots across Mettupalayam, Coonoor, and Ooty with interactive distance radius slider & Google Maps navigation.
- **🗳️ Group Polls**: Real-time group decision voting with live percentage bars.
- **📅 Trip Planner**: Oct 9 - 11, 2026 (Friday, Saturday, Sunday) Day-by-Day schedule itinerary.
- **🚗 Journey Tracker**: Roadtrip route tracker for distance, fuel, tolls, and food stops.
- **📍 Places Visited & Trail Path**: Strava-style customizable trail route path with interactive node completion & End of Trip Wrap summary card.
- **⚡ Fun Zone**: Spin-the-wheel randomizer, Win95 Ooty Trip Bingo, automated Friend Roast leaderboard & Vaporwave Lo-Fi music player.
- **🎨 Theme Engine**: Switch between Cyberpunk Glitch ⚡, Vaporwave Outrun 🌅, and 90s Win95 Retro 💾 themes.

## 🛠️ Tech Stack

- React + Vite
- TailwindCSS
- Firebase SDK (Firestore + Realtime Database)
- Lucide React Icons & Canvas Confetti

## 🚀 Deployment

Hosted on GitHub Pages using `gh-pages`:
```bash
npm run deploy
```
